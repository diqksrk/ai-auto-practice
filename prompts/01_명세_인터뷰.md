# 실습① 명세 인터뷰 프롬프트

아래를 그대로 복사해 AI 에게 보내세요. `specs/proration.md` 파일 내용도 같이 붙여 넣습니다.
**7분짜리 실습입니다.** 질문 10개 중 위에서 5개만 직접 답하고, 나머지는 맨 아래 "강사 기본값" 으로 답해도 됩니다.

```
아직 코드는 쓰지 마.
구독 요금 일할 계산 기능의 명세를 쓰려고 해. 아래는 기획자 메모와 빈 명세야.

1. 이 메모만으로는 구현자가 추측해야 하는 빈칸을, 틀렸을 때 피해가 큰 순서로 10개 질문해 줘.
   질문마다 "이걸 정하지 않으면 생길 수 있는 잘못된 청구 예시" 를 한 줄씩 붙여 줘.
2. 내가 답하면, 명세의 3. 규칙(R1~R6)과 4. 예시 표(8행 이상)를 채워 줘.
   예시 표의 기대값은 반드시 숫자로 쓰고, 계산 과정을 괄호로 보여 줘.
3. 내가 답하지 않은 것은 추측하지 말고 6. 열린 질문에 [확인 필요] 로 남겨.

(여기에 specs/proration.md 내용 붙여 넣기)
```

## 답할 때 기준 (강사 기본값 — 팀에서 다르게 정해도 됩니다)
- 한 달은 그 달의 실제 날짜 수 (28·29·30·31)
- 시작일·종료일 모두 포함
- 원 미만 버림
- 쿠폰이 금액보다 커도 청구액은 0원
- 청구월 밖의 날은 세지 않는다 (지난달부터 쓰던 고객은 청구월 1일부터, 청구월과 안 겹치면 0원)
- 쿠폰은 일할한 금액에 적용하고, 할인액도 원 미만 버림
- 종료일이 시작일보다 앞서거나 · 월 요금이 음수거나 · 정률이 0~100% 밖이면 오류

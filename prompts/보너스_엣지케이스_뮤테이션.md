# (보너스) AI 로 엣지 케이스 뽑고 뮤테이션으로 채점

**새 대화**에서, 명세만 줍니다. (코드를 짠 대화에서 물어보면 자기 코드의 가정을 따라갑니다.)

```
너는 이 기능을 깨뜨리려는 테스터야. 아래 명세만 보고, 구현이 틀리기 쉬운 경계 사례를 15개 뽑아 줘.

다음 관점을 빠짐없이 훑어:
- 경계값: 0, 1, 최대, 말일, 같은 날 시작·종료
- 달력: 28·29·30·31일 달, 윤년, 청구월 앞뒤로 걸친 기간
- 돈: 버림/반올림, 음수, 할인 한도와 딱 같은 값
- 입력 오류: 순서가 뒤집힌 날짜, 범위를 벗어난 %
- 명세에 없는 것: 두 규칙이 부딪히는 경우

각 사례마다 [입력 / 기대값 / 근거 규칙 번호 / 왜 틀리기 쉬운가] 를 표로.
명세만으로 기대값이 안 나오면 추측하지 말고 [확인 필요] 로 표시해.
그다음 [확인 필요] 가 아닌 것만 tests/test_edge.py 로 만들어 줘.

(여기에 specs/proration.md 붙여 넣기)
```

## 채점
```bash
python -m pytest
python tools/mutate.py
```
- "살아남음" 줄 = 테스트가 그 줄을 제대로 확인하지 않는다는 뜻
- 살아남은 변이마다 둘 중 하나로 판정: **잡을 테스트를 추가** / **바꿔도 결과가 같은 변이(무시)**
- 목표: 점수 80% 이상 (`python tools/mutate.py --min-score 80`)

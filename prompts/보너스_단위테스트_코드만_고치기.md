# (보너스) 단위 테스트는 그대로, 코드만 고치기 — pytest 판

```
python -m pytest 를 실행하면 tests/test_spec.py 가 실패해.
src/billing/proration.py 만 고쳐서 모든 테스트를 통과시켜 줘.

규칙:
- tests/ 폴더의 파일은 절대 수정하지 마.
- 실패한 테스트가 명세(specs/proration.md)와 다르다고 생각되면, 고치지 말고 멈추고 나에게 물어봐.
- 돈 계산은 정수 연산만. float 금지.
- 끝나면 python -m pytest 실행 결과를 그대로 보여 줘.
```

## 끝나고 직접 확인
```bash
python -m pytest          # 전부 통과?
git diff --stat tests/    # 커밋한 뒤로 테스트 파일이 바뀌지 않았나? (아무것도 안 나와야 정상)
git status tests/         # 커밋 안 한 새 테스트 파일(??)이 있으면 diff 에 안 보인다 — 먼저 커밋
```

**가장 흔한 거짓 초록불**: AI 가 테스트의 기대값을 코드에 맞게 바꿔서 통과시키는 것. `git diff tests/` 로 꼭 확인하세요.

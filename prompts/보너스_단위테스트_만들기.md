# (보너스) 명세로 단위 테스트 만들기 — pytest 판

**새 대화**에서 시작하세요. 코드 파일은 보여주지 않습니다. 명세만 줍니다.

```
아래 명세의 "4. 예시" 표를 pytest 테스트로 옮겨 줘.

- 파일: tests/test_spec.py
- 함수: from billing.proration import Coupon, calculate_charge
  시그니처: calculate_charge(monthly_price, start, end, year, month, coupon=None) -> int
  Coupon(kind="fixed" | "percent", value, max_discount=None)
- 예시 한 행 = 테스트 하나. pytest.mark.parametrize 를 쓰고, id 에 예시 번호를 넣어.
- 기대값은 명세 표에서만 가져와. 네가 계산해서 바꾸지 마.
- 오류 행은 pytest.raises(ValueError) 로.

(여기에 완성한 specs/proration.md 붙여 넣기)
```

테스트 파일이 생기면 **바로 커밋**합니다. 새 파일은 커밋해 두어야 나중에 `git diff` 로 바뀐 게 보입니다.
```bash
git add tests/test_spec.py
git commit -m "명세 예시 테스트"
```

실행: `python -m pytest` → **빨간불이 나오면 성공**입니다. 명세가 코드의 버그를 잡은 것입니다.
